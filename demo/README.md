# demo/

This directory contains demonstration scripts and walkthroughs for the Stellar-Save platform.
It is **not part of any build pipeline** — no build tool (Vite, tsc, Vitest, Jest) includes
this directory. Files here are pure documentation.

## Contents

| File | Purpose |
|------|---------|
| `demo-script.md` | Step-by-step interactive demo guide for showcasing the full ROSCA flow on testnet. Covers account setup, group creation, contributions, and payouts using the Stellar CLI. Referenced from the root README "Run Demo" section. |

## Usage

Follow the steps in [`demo-script.md`](./demo-script.md) when running a live demo or onboarding
session. Requires a deployed testnet contract and funded Stellar testnet accounts.
